# AgentFence Product Demo Video Script

## Purpose and Scope

This 45–60 second product video demonstrates a governed agent workflow. It must show actual product concepts accurately: the user chooses a runtime, registers a tenant-bound agent, defines a narrow policy boundary, routes an action through AgentFence, and inspects the trace. The video must state that the controlled OWASP assessment is non-destructive and that a policy allow releases an action but does not prove the target completed a business transaction.

| Time | Visual | On-screen copy | Narration |
|---|---|---|---|
| 0–6s | Red glass AgentFence hero, agent intent moving toward a protected boundary. | “The red line between agents and consequences.” | “AI agents can now act in enterprise systems. AgentFence governs consequential actions that use its integrated control path.” |
| 6–15s | First-agent wizard shows Cloud agent and Managed browser agent choices. | “Choose the runtime. Register a workload identity.” | “Start with a cloud agent or a managed browser agent. AgentFence binds the workload to a tenant, owner, environment, and risk level.” |
| 15–25s | Wizard boundary step highlights CRM action, approved destination, and approval-required mode. | “Define the first boundary.” | “Set a narrow policy: which tool, which action, what data sensitivity, and which destination. Begin with approval when the impact is high.” |
| 25–37s | Tool Gateway decision path shows agent intent → Data Guard → policy → approval → released target boundary. | “Allow. Block. Or require approval.” | “Before an integrated API or browser action runs, AgentFence evaluates identity, policy, inbound and outbound data sensitivity, destination, scope, and the approval requirement.” |
| 37–48s | Action Trace displays live decision hops, audit evidence, and sanitized target outcome. | “Trace every governed action.” | “Action Capture and Action Trace show the privacy-safe decision record, approval state, audit evidence, and reported downstream outcome.” |
| 48–56s | Architecture visual transitions from cloud and browser agents through AgentFence to enterprise systems and SOC. | “One integrated control path across cloud, browser, and enterprise systems.” | “Use one control plane across cloud SDK and managed-browser-wrapper workflows, data systems, and regulated operations.” |
| 56–60s | Closing logo and CTA. | “AgentFence. Govern action, not just prompts.” | “AgentFence. Start with one agent. Keep authority contained.” |

## Production Prompt

Create a 60-second cinematic enterprise SaaS product demo in a premium red, charcoal, and cyan glassmorphism visual system. The subject is AgentFence, a zero-trust governance control plane for integrated AI agent actions. Show an abstract AI agent intent approaching a red shield boundary; then a polished UI onboarding wizard with two choices: Cloud SDK and Managed browser wrapper; then a policy form with CRM customer-read action, approved destination, and human approval gate; then an animated governed action rail with labels Identity, Data Guard, Policy Engine, Approval, Audit Evidence, and Target Outcome; then a clean enterprise architecture graphic showing cloud SDK and managed-browser-wrapper agents converging on an action gateway before enterprise SaaS, internal APIs, databases, and SOC operations. Include a brief boundary caption: “Direct calls that bypass the integration remain an enterprise responsibility.” Use accurate, restrained cybersecurity visuals, readable typography, no terminal hacking imagery, no padlock rain, no fake dashboards, and no fabricated security statistics. Finish on AgentFence logo with the tagline “Govern action, not just prompts.”

## Compliance Note

The finished video should be reviewed against the live application before public use. It must not claim universal prevention, regulatory certification, live attack execution, or customer outcomes that have not been independently measured.
